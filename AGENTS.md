# Project Agent Instructions

## Required workflow

- For every code or configuration change, load and follow `.agents/skills/grill-with-doc/SKILL.md`.
- Read the repository context before writing: applicable instructions, relevant documentation, source code, tests, configuration, schemas, and API contracts.
- Do not start editing until the requested behavior and any material ambiguities are resolved and a concise implementation plan has been stated.
- Ask only questions that can materially affect the implementation. Whenever you ask, provide mutually exclusive choices, a recommended option, and an `Other` option.
- Use safe defaults for minor, reversible details and state those assumptions.
- Preserve existing behavior, patterns, public interfaces, error handling, and unrelated changes unless the request explicitly requires otherwise.
- After editing, inspect the diff and run the most relevant available checks; report the result and any limitations.

## Project skill

The project workflow skill is [`.agents/skills/grill-with-doc/SKILL.md`](.agents/skills/grill-with-doc/SKILL.md). It is documentation-first and requires reading relevant code before implementation.
